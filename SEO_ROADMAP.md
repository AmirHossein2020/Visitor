# VisitorKar SEO Roadmap

## TECHNICAL SEO — completed in code

- Crawlable static HTML snapshots for the homepage, pricing, six intent pages and legal/trust pages.
- Unique titles, descriptions, canonical and Open Graph metadata.
- Public-only XML sitemap and robots policy excluding private application routes.
- Semantic Persian content, internal links, local font and lazy-loaded application routes.
- Honest SoftwareApplication/WebSite identity without fabricated ratings, reviews or statistics.

## POST-LAUNCH SEO — ongoing work

### Month 1

- Connect Google Search Console, submit sitemap and inspect indexing/canonical coverage.
- Record real impressions, queries, Core Web Vitals and conversion baselines.
- Complete privacy, terms and contact pages with verified legal/operator information.
- Resolve crawl errors and improve snippets based on actual query language.

### Month 2

- Publish a small number of expert, workflow-based guides derived from real user questions.
- Strengthen relevant internal links between guides, feature pages and pricing.
- Improve pages receiving impressions but weak click-through; do not create thin keyword variants.
- Seek legitimate mentions from partners, professional communities and owned profiles.

### Month 3

- Compare trial/registration conversion by landing intent without collecting business-record data.
- Refresh content using Search Console evidence and support themes.
- Earn useful backlinks through original templates, checklists or product education.
- Review brand mentions, duplicate content, mobile CWV and sitemap freshness.

Rankings are not guaranteed; decisions should follow verified search and conversion data.
